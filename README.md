# أكاديمية المبرمج المجهول

موقع كورسات أمن سيبراني (عربي، RTL) يشتغل على GitHub Pages.

## إضافة وتعديل الكورسات
1. افتح الموقع واضغط **⚙ لوحة التحكم**.
2. سوّي Fine-grained token من https://github.com/settings/personal-access-tokens/new
   - Repository access: هذا الريبو فقط
   - Permissions → Contents: **Read and write**
3. الصق التوكن بلوحة التحكم ← دخول.
4. أضف/عدّل/احذف الكورسات والدروس. كل حفظ ينكتب بملف `courses.json` ويظهر للزوار خلال دقيقة.

التوكن ينحفظ بمتصفحك فقط.

## الملفات
- `index.html` — الموقع كامل
- `courses.json` — بيانات الكورسات والإعدادات
